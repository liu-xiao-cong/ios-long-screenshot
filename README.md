# Cong的长截图

[打开 App](https://liu-xiao-cong.github.io/ios-long-screenshot/)

通过 Safari 打开，再从分享菜单选择“添加到主屏幕”。无需 App Store、开发者账号或登录。

支持截图排序、自动去重拼接、滚动录屏导入、上下裁剪、隐私涂黑、可自定义文字水印和 PNG 分段导出。画面仅在浏览器本地处理，不上传服务器。

一次最多 30 张截图或 60 秒录屏。生成宽度最高 900 px、总高最高 40,000 px，每段最高 8,000 px。自动拼接适用于单向滚动的静态内容；匹配不可靠时会停止并提示。视频格式支持取决于浏览器。

刷新或关闭页面会丢失当前编辑，离开前请导出。本项目是原型；手机视频解码、主屏幕安装和相册保存仍需真机确认。

这是纯静态网站，main 分支根目录直接由 GitHub Pages 发布。修改静态文件后推送即可更新；更新应用时递增 sw.js 中 CACHE 版本。

水印支持四角、居中和全图平铺，文字、字号、不透明度、颜色均可调整；每个导出分段都会添加，裁剪后自动重新定位。默认关闭。
